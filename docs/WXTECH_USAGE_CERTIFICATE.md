## 本質

本サイネージの気象コンテンツは、気象庁・環境省の公開データではなく、ウェザーニューズ WxTech「1kmメッシュ ピンポイント天気予報・体感予報」API（`/api/v1/ss1wx`）から取得した予報データを表示用に整形し、LED 上で循環表示しているものである。

- 画面の「現況」は観測実況ではなく、API 応答 `srf[0]`（短期予報）を用いる。
- 気象数値・天気コード・予報時刻はすべて WxTech 由来である。
- `feeltmp`（体感温度）は WBGT（暑さ指数）ではない。画面上も「体感」と明記する。
- 背景色の段階（気温警戒／気温危険）は WxTech 公式色ではなく、気温 `temp` に対する表示側しきい値（31℃／35℃）である。

## 利用エンドポイント・運用

| 項目 | 内容 |
|------|------|
| エンドポイント | `GET https://wxtech.weathernews.com/api/v1/ss1wx` |
| 認証 | `X-API-Key`（プロキシ側保持。キー本文は非掲載） |
| 取得間隔 | 約15分（キャッシュ900秒） |
| 制限 | 1日1,000回 / 秒間10回 |

## 利用フィールド

### 短期予報 srf（現況）

`date`, `wx`, `temp`, `feeltmp`, `feelidx`, `rhum`, `prec`, `wnddir`, `wndspd`, `arpress`

### 中期予報 mrf（4日予報等）

`date`, `wx`, `maxtemp`, `mintemp`, `pop`

## 画面構成

- 現況: 天気／気温／体感／湿度／降水量／風向／風速／気圧／最高・最低
- 体感・気温対比
- 4日予報
- 下帯: 予報日時・天気・気温・体感、必要時「気温警戒／危険」「気温基準」

## システム構成

LED 端末 HTML（`public/signage/wx-cube-4face.html`）→ Google Apps Script プロキシ（`gas/WxTechProxy.gs`）→ WxTech API。  
API キーは端末に置かない。

## 知的財産・取扱い

WxTech API サービス利用規約に従い、提供データ等の知的財産は株式会社ウェザーニューズに帰属する。  
本利用は契約目的の範囲での現場表示であり、提供データの第三者への再配布は行わない。

## 天気アイコン特記

`https://tpf.weathernews.jp/wxicon/152/[天気コード].png` を用いる場合がある。
