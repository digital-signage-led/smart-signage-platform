# 白ベース3段デザイン仕様（気象警報一覧）

発表中の**気象警報・注意報だけ**を、一覧として見せる画面です。  
**発表されている期間のみ**表示し、解除・未発表のときは出しません。

| 項目 | 内容 |
|------|------|
| 対象シーン | `sceneRainWarn`（`ra-white-mode` / `ra-white-bundle`） |
| 画面サイズ | **512 × 128 px** |
| 用途 | 気象庁が発表中の警報・注意報をすべて流す一覧 |
| 出さないもの | **地震・緊急地震速報**（別シーン `sceneQuake`）／熱中症アラート／避難情報 |
| プラットフォーム | `wbgt-cube-*-4face.html` / `*-5face*.html`（`.ra-white-*`） |
| 正本相当 | `index-4face.html` |
| 確認URL例 | `…html?rainwarn=3&rainwhite=1` または白ベース既定時の `?rainwarn=all` |

---

## 1. 役割（いつ・何を出すか）

1. **気象警報・注意報が1件以上発表中**のときだけ割り込み表示する  
2. 中央帯に、**いま発表中の項目名をすべて**横スクロールで流す（一覧）  
3. 上帯で「どこで・いつ・何の系統が出ているか」を示す  
4. 下帯で、**発表中の段階だけ**（注意報／警報／危険警報／特別警報）を示す  
5. すべて解除されたら、この画面自体を出さない（通常ループのみ）

スクロール順（段階）: **注意報 → 警報 → 危険警報 → 特別警報**

---

## 2. 全体レイアウト（3段）

```
+------------------------ 512 px ------------------------+
| 上帯 40px  青文字（地域／発表時刻／種別まとめ）          |  クリーム背景
+--------------------------------------------------------+
| 中央帯 約54px  色付きチップが右→左に流れる（一覧）      |  薄いグレー帯
+--------------------------------------------------------+
| 下帯 約32px  発表中段階のピル（注意報〜特別警報）       |  クリーム背景
+--------------------------------------------------------+
高さ合計 128 px
```

| 帯 | 高さ | 背景 | 役割 |
|----|------|------|------|
| **上帯（1段目）** | **40 px** | `#FFF9F0` | 発表メタ情報（何が・どこで・いつ） |
| **中央帯（2段目）** | **約 54 px** | 帯 `#D5D1C9` ／チップは段階色 | **発表中の警報名一覧**をスクロール |
| **下帯（3段目）** | **約 32 px**（ピル高さ 24 px） | `#FFF9F0` | 発表中の**段階ラベル**のみ |

キャンバス背景もクリーム `#FFF9F0`（`.ra-white-canvas`）。

---

## 3. 1段目（上帯）— 何が発表されているか

横スクロールのヘッダー（512 px 幅を2セット並べてシームレス）。

| 要素 | クラス | 色 | サイズ | 内容例 |
|------|--------|-----|--------|--------|
| 地域 | `.ra-white-area` | `#0854A8` | 15 px / 900 | `熊本市の地域で発表されています` |
| 発表時刻 | `.ra-white-time` | `#0854A8` | 14 px / 700 | `発表 8/11 14:30` |
| 種別まとめ | `.ra-white-what` | `#0854A8` | 14 px / 700 | `大雨・洪水・雷` など（発表中の現象名を要約） |

配置: 左→地域、中央寄り→時刻、右寄りに伸びる→種別まとめ（長いときは省略）。

**ポイント:** 1段目は「状況説明」。個別の警報名の詳細一覧は中央帯に任せる。

---

## 4. 2段目（中央帯）— 発表中項目の一覧

| 項目 | 仕様 |
|------|------|
| 帯の高さ | 約 54 px（画面中央） |
| 帯色 | `#D5D1C9` |
| チップ | 角丸・白文字・横並びスクロール |
| チップ文字 | 約 **24 px** / 900（はみ出し時は縮小） |
| チップ表示名 | 正式名称寄り（例: `大雨警報` `洪水注意報`）。短縮時は末尾の「注意報／警報」等を落とす場合あり |
| 動き | 右→左、シームレス。発表中の件を**すべて**流す |

### チップ背景色（段階）

| 段階 | クラス | 背景 | 文字 |
|------|--------|------|------|
| 注意報 | `.ra-white-mid-advisory` | `#CDB800` | 白 |
| 警報 | `.ra-white-mid-warning` | `#D62828` | 白 |
| 危険警報 | `.ra-white-mid-danger` | `#AB00AA` | 白 |
| 特別警報 | `.ra-white-mid-special` | `#000000` | 白 |

強調色（画面全体のトーン）は、発表中で**最も重い段階**に合わせる。

---

## 5. 3段目（下帯）— 発表中の段階だけ

| 項目 | 仕様 |
|------|------|
| ピル高さ | 24 px |
| ピル幅 | 列あたり最大 128 px 内 |
| 文字 | 11 px / 900 / 白 |
| 形 | カプセル（`border-radius: 9999px`） |
| 表示 | **いま発表がある段階だけ**（未発表の段階は出さない） |

| 段階 | ラベル | 背景 |
|------|--------|------|
| 注意報 | 注意報 | `#CDB800` |
| 警報 | 警報 | `#D62828` |
| 危険警報 | 危険警報 | `#AB00AA` |
| 特別警報 | 特別警報 | `#000000` |

早期注意情報（レベル1）は白ベース運用では原則対象外（運用から除外）。

---

## 6. タイポグラフィ・フォント

| 用途 | フォント | 太さ |
|------|----------|------|
| 上帯・中央・下帯すべて | Noto Sans JP | 700〜900 |
| 数字（時刻） | 同上で可 | 700 |

原則:

- 上帯は**青**、中央チップ／下ピルは**白文字＋段階色地**
- 遠距離可読のため細い線・薄いグレー文字は使わない
- 長い名称はフォント縮小 → それでも厳しければスクロールに任せる

---

## 7. モーション

| 動き | 目安 |
|------|------|
| 上帯スクロール | 約 0.75 px/frame |
| 中央帯スクロール | 同系（一覧を読み切れる速度） |
| 下帯スクロール | 同系（段階ピルが複数あるとき） |
| ループ | 同一内容を2セット以上並べ、1セット幅で継ぎ目なく周回 |

---

## 8. 対象コンテンツ（気象のみ）

### 含める

- 警戒レベル対象: 大雨・洪水（氾濫）・土砂・高潮 などの注意報／警報／危険／特別  
- その他気象: 暴風・強風・波浪・大雪・雷・濃霧 など、**気象庁の注意報・警報・特別警報**

### 含めない（別デザイン）

| 種別 | 出し方 |
|------|--------|
| 緊急地震速報・地震情報 | 黒ティッカー／観測パネル（`sceneQuake`） |
| 熱中症アラート | 紫／黒の専用テロップ |
| 避難情報（市町村） | 避難専用テロップ |

---

## 9. デザイン変更時のチェック

1. 3段の役割を混ぜない（上＝メタ、中＝一覧、下＝段階）  
2. 地震・熱中症・避難を白ベース中央に載せない  
3. 未発表の段階ピルを下帯に残さない  
4. 色は気象庁段階色（黄／赤／紫／黒）に合わせる  
5. 512×128 からはみ出さない  

---

## 10. 実装対応表

| 仕様 | コード |
|------|--------|
| 白ベース既定ON | `RAIN_WHITE_DESIGN = query.get('rainwhite') !== '0'` |
| 色付き3段へ | `?rainwhite=0` |
| スクロール順 | `RAIN_WHITE_SCROLL_ORDER = ['advisory','warning','danger','special']` |
| 下帯は発表中のみ | `issuedWhiteLevels_()` |
| 上帯速度 | `RA_WHITE_BAND_SCROLL_PX = 0.75` |
