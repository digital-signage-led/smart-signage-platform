# 通常天候デザイン仕様（時刻・観測・予報）

通常ループで流れる**時刻・天気（雨など）・WBGT・4日予報・多言語指針**の帯の太さとフォントサイズです。  
割り込み（警報・地震・熱中症）は別紙。実装の正は `index-4face.html`。

**データ源について:** 本紙は見た目のみ。気象庁・環境省は標準データ源、環境クラウド／ウェザーニュース等は  
[SIGNAGE_EXTERNAL_API.md](./SIGNAGE_EXTERNAL_API.md)（外部API）。シーン出し分けは [SIGNAGE_CONTENT_POLICY.md](./SIGNAGE_CONTENT_POLICY.md)。

| 項目 | 内容 |
|------|------|
| 対象 | ①時刻 → ②気象観測 → ③WBGT → ④4日予報 → ⑤多言語指針 |
| 画面 | **512 × 128 px**（128×128 × 4列） |
| 方針 | **文字優先・高コントラスト**。帯の太さ・既定フォントは変更しない |
| 正本相当 | `index-4face.html` |
| プラットフォーム | `wbgt-cube-*-4face.html` / `*-5face*.html` |
| 標準データ | 気象庁 AMeDAS・予報／環境省 WBGT（GAS） |
| 外部API案件 | ECS 等は別エンジン・別紙（上記 EXTERNAL_API） |

## 1. 共通の帯（通常シーン）

```
+-- 上バー 32 px --+  ラベル（日付・項目名・レベル）
|-- 本体 64 px ----|  時刻・数値・天気アイコン
+-- 下帯 32 px ----+  クリーム #fff9f0・黒文字
高さ合計 128 px（上＋本体＝96 px がスクロール領域）
```

| CSS変数 | 値 |
|---------|-----|
| `--led-foot-bar-h` | **32 px** |
| `--led-col-body-h` | **64 px** |
| `--led-col-main-h` | **96 px** |
| `--led-foot-font` | **15 px** |
| `--led-foot-site-font` | **15 px** |
| `--led-foot-bar-bg` | `#fff9f0` |

| 帯 | 高さ | 役割 |
|----|------|------|
| 上バー | **32 px** | 日付／天気／気温／降水量 など |
| 本体 | **64 px** | 数値・時刻・天気アイコン |
| 下帯 | **32 px** | 地点・出典・短いメッセージ |

文字色の基本:

| 背景 | 文字 |
|------|------|
| 青・橙・赤など濃色 | `#ebebeb` |
| 黄・橙黄（注意・警戒） | `#000000`（`col-bg-dark-text`） |
| 下帯クリーム | `#1a1a1a` |

フォント:

| 用途 | 書体 |
|------|------|
| 日本語ラベル | Noto Sans JP |
| 数字（時刻・気温・雨量・WBGT） | Inter |

## 2. ① 時刻（scene1）

```
+ 日付 20px ×4     +  上 32
| HH:MM 42px ×4    |  中 64（4面同一）
+ 下帯メッセージ…  +  下 32 クリーム
```

| 要素 | クラス | サイズ | 太さ | 色 |
|------|--------|--------|------|-----|
| 日付 | `#scene1 .s1-bar-label` | **20 px** | 700 | `#ebebeb`（濃色時） |
| 時刻 時:分 | `.time-val` / `.clock-hm` | **42 px**（既定） | 800 | 同上 |
| 下帯メッセージ | `.s1-wbgt-msg-compact` 等 | **15 px** | 700 | `#1a1a1a` |
| 下帯・地点 | `.s1-wbgt-site-label` | **15 px** | 700 | `#1a1a1a` |

補足:

- 時刻は幅超過時 **28 px** まで縮小（通常は 42 px）
- 秒は出さない／タイムゾーンは Asia/Tokyo（`仕様書_時刻同期.md`）
- 下帯は 256 px 単位でシームレス横スクロール

## 3. ② 気象観測（scene2）— 天気・雨・気温など

天気アイコン／気温／**降水量（雨）**／風向／風速／湿度／気圧／最高最低／瞬間風速を順送り。

```
+ ラベル 20px +
| 数値／アイコン |  ← 128×96（上32＋本体64）
+ 下帯メタ 15px +
```

### 3.1 共通（#scene2 上書き後の本番値）

| 要素 | クラス | サイズ | 太さ |
|------|--------|--------|------|
| 上バー・項目名 | `#scene2 .s2-bar-label` | **20 px** | 700 |
| 数値（気温・雨量・風速・湿度・気圧 等） | `#scene2 .s2-num` | **44 px** | 800 |
| 単位（℃・mm・m/s・%・hPa） | `#scene2 .s2-unit` | **20 px** | 600 |
| 風向テキスト | `#scene2 .s2-dir-text.dir-val` | **34 px** | 800 |
| 天気アイコン | `#scene2 .weather-svg` | **54 × 54 px** | — |
| 下帯メタ | `.s2-meta-msg-scroll` | **15 px** | 700 |

### 3.2 パネル別（雨の日を含む）

| パネル `data-s2` | 上バー文言 | 本体の見え方 |
|------------------|-----------|--------------|
| `weather` | 天気 | SVG アイコン 54px（晴れ／曇り／**雨** 等） |
| `temp` | 気温 | 数値 44px ＋ `℃` 20px |
| `rain` | 降水量 | 数値 44px ＋ `mm` 20px |
| `winddir` | 風向き | 方角テキスト 34px |
| `wind` | 風速 | 数値 44px ＋ `m/s` 20px |
| `humi` | 湿度 | 数値 44px ＋ `%` 20px |
| `pres` | 気圧 | 数値 44px ＋ `hPa` 20px |
| `tmaxmin` | 最高／最低 | 白カード内 高 **40px** 赤／低 **40px** 青、区切り 40px、単位 16px |
| `gust` | 最大瞬間風速 | 数値 44px ＋ `m/s`（ラベルは長いので compact 時 12px もあり） |

最高・最低カード:

| 要素 | サイズ | 色 |
|------|--------|-----|
| 最高 | **40 px** | `#e02020` |
| 最低 | **40 px** | `#2060e0` |
| 区切り `/` | **40 px** | `#1a1a1a` |
| 単位 | **16 px** | `#1a1a1a` |
| カード地 | — | `#ffffff`・角丸 8px |

## 4. ③ 暑さ指数 WBGT（scene4）

```
+ 暑さ指数／WBGT 20px +
|  28.5 ℃  44px／20px  |
+ 出典テキスト 15px…  +
```

| 要素 | クラス | サイズ | 太さ |
|------|--------|--------|------|
| 上バー | `#scene4 .fc-bar-label` | **20 px** | 700 |
| WBGT 数値 | `.fc-wbgt-num` | **44 px**（最大約56まで収める） | 800 |
| 単位 | `.fc-wbgt-unit` | **20 px** | 700 |
| 下帯 | `.fc-lv-msg-compact` 等 | **15 px** | 700 |

背景色は WBGT レベルで変化（ほぼ安全〜危険）。詳細色は `仕様書_デザイン.md` §3.2。

## 5. ④ 4日予報（scene5）— 雨マーク含む

```
+ 今日 22px | 明日 | 明後日 | 明々後日 +
| 天気58px ／ 気温52px | … |
+ 地点 15px… +
```

| 要素 | クラス | サイズ | 太さ |
|------|--------|--------|------|
| 日付ラベル | `#scene5 .s2-bar-label` | **22 px** | 700 |
| 天気アイコン | `#scene5 .d5-body .weather-svg` | **58 × 58 px** | — |
| 気温数値 | `#scene5 .d5-body .s2-num` | **52 px** | 800 |
| 単位 ℃ | `#scene5 .d5-body .s2-unit` | **24 px** | 600 |
| 区切り | `#scene5 .d5-sep` | **38 px** | 700 |
| 下帯 | 共通 foot | **15 px** | 700 |

今日列のみ **2 px** 枠（濃色背景＝白枠／注意・警戒＝黒枠）。

## 6. ⑤ 多言語 WBGT 指針（scene3）

```
+ レベル名 20px ×4（上32） +
| 256×2  2行テロップ（本体64） |
+ 指針文 15px（下帯）… +
```

| 要素 | クラス | サイズ | 太さ |
|------|--------|--------|------|
| 上バー・レベル名 | `.t3-lv-label` | **20 px** | 700 |
| 本文 1・2行 | `.t3-l1` / `.t3-l2` | 言語表に従い（はみ出し時縮小） | 900 |
| 下帯指針 | `#scene3 .t3-guid-bar` 内 | **15 px** | 700 |

本文は 256 px モジュール内で横スクロール。日・英・インドネシア・フィリピン・ベトナムを順切替。

## 7. 寸法・フォント早見（通常ループ）

| シーン | 上バー | 本体の主役 | 下帯 |
|--------|--------|------------|------|
| ①時刻 | 日付 **20** | 時刻 **42** | **15** |
| ②観測（雨・気温等） | 項目 **20** | 数値 **44**／単位 **20**／天気 **54px** | **15** |
| ③WBGT | **20** | 数値 **44**／単位 **20** | **15** |
| ④4日予報 | 日付 **22** | 気温 **52**／天気 **58px** | **15** |
| ⑤多言語 | レベル **20** | 2行テロップ | **15** |

帯の太さは全シーン共通: **上 32 / 中 64 / 下 32**。
