# 沖縄 DS 気象・防災情報 — 表示仕様書

| 項目 | 内容 |
|------|------|
| 対象システム | 沖縄 DS 気象・防災情報（320キューブ / 4面 LED） |
| 設置想定 | 沖縄県島尻郡久米島町（久米島） |
| 本番ファイル（DS 原典） | `index-4face.html` |
| 本番ファイル（本プラットフォーム） | **`wbgt-cube-okinawa-kumejima-4face.html`** |
| 確認メニュー | `wbgt-cube-okinawa-kumejima-demo.html` |

---

## 1. 画面の基本仕様

| 項目 | 仕様 |
|------|------|
| 表示サイズ | **512×128 px**（128×128 パネル×4列＝4面） |
| 通常運用 | 時刻・気象観測・WBGT・予報をループ |
| 防災割り込み | 警報・注意報／熱中症アラート／避難／地震が**発表されているときだけ**割り込み |
| 警報データ | 気象庁 **r8 のみ**（旧API・GASの古い発表は使わない。解除後は即非表示） |
| 出典表記 | 出典：気象庁・環境省データ |

### 1.1 表示の流れ

```
時刻＋WBGT → 気象観測 → WBGT表示 → 4日予報 → 多言語WBGT
     ↑                                              ↓
     └────（ループ）←── 防災発表があるときだけ割り込み ─┘
```

防災割り込みの例: 緊急地震 → 熱中症アラート → 避難情報 → 気象警報・注意報 → 通常ループへ戻る

## 2. 通常表示（気象庁・環境省）

| 画面 | 内容 | データ元 |
|------|------|----------|
| 時刻＋WBGT下帯 | 現在時刻・WBGT段階 | 環境省 WBGT |
| 気象観測 | 気温・湿度・風など | 気象庁 AMeDAS |
| WBGT表示 | 暑さ指数・指針 | 環境省 |
| 4日予報 | 天気・気温など | 気象庁予報 |
| 多言語WBGT | WBGTメッセージ | 環境省 |

---

## 3. 防災割り込み（発表時のみ）

発表されている項目だけ表示。解除・未発表は出さない。

| 種別 | 内容 |
|------|------|
| 気象警報・注意報 | 色付き3段で**1件ずつ**流す（例: 黄・警戒レベル2・土砂災害注意報）。まとめ白帯は `?rainwhite=1` |
| 熱中症アラート | 環境省（沖縄県） |
| 避難情報 | 自治体発表時（設定または `?evac=`） |
| 地震 | 緊急地震速報／地震情報 |

防災のみにする場合は `?bosaiOnly=1` または `SignageConfig.bosaiOnly: true`。
