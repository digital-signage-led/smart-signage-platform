# デザイン仕様（用法）

LED サイネージ `index-4face.html` の色・文字・配置・大きさの使い方です。  
表示内容（何を出すか）は `仕様書_表示内容.md` を参照してください。

住之江（四面 / 五面・ロゴ列あり）の詳細は [SIGNAGE_DESIGN_SUMINOE.md](./SIGNAGE_DESIGN_SUMINOE.md) を参照。  
緊急地震速報（512×128 固定）は [SIGNAGE_DESIGN_QUAKE.md](./SIGNAGE_DESIGN_QUAKE.md) を参照。  
気象警報・注意報の白ベース3段は [SIGNAGE_DESIGN_RAIN_WHITE.md](./SIGNAGE_DESIGN_RAIN_WHITE.md) を参照。  
警報・注意報情報（警戒レベル色3段・`ra-hero`）は [SIGNAGE_DESIGN_RAIN_HERO.md](./SIGNAGE_DESIGN_RAIN_HERO.md) を参照。  
通常天候（時刻・観測・予報・多言語）は [SIGNAGE_DESIGN_NORMAL.md](./SIGNAGE_DESIGN_NORMAL.md) を参照。  
仕様の3枠（デザイン／コンテンツ政策／外部API）は [docs/README.md](./README.md) を参照。  
**コンテンツ政策**（何を出すか）は [SIGNAGE_CONTENT_POLICY.md](./SIGNAGE_CONTENT_POLICY.md)。  
**外部API**（環境クラウド・ウェザーニュース等）は [SIGNAGE_EXTERNAL_API.md](./SIGNAGE_EXTERNAL_API.md)。  
グリッド（128）・縦3段（32/64/32）・WBGT 5段階色は共通です。

| 項目 | 内容 |
|------|------|
| 対象 | 本番 `index-4face.html`（4面 512×128） |
| 会場想定 | 熊本県熊本市 |

## 1. キャンバスとグリッド

### 1.1 画面サイズ

| 項目 | 値 |
|------|-----|
| 表示領域 | **512 × 128 px** |
| 分割 | 128 × 128 px の列 × **4** |
| ロゴ列 | 4面運用では非表示（`layout-512`） |

```
+-------- 512 px --------+
| 128 | 128 | 128 | 128 |  <- 高さ 128 px
+------------------------+
```

### 1.2 縦の基本帯（通常シーン共通）

| 帯 | 高さ | 役割 |
|----|------|------|
| 上バー | **32 px** | ラベル（日付・項目名・レベル名） |
| 本体 | **64 px** | 数値・時刻・アイコン |
| 下帯 | **32 px** | 地点名・出典・補足（クリーム背景） |
| 上＋本体 | **96 px** | スクロール領域の高さ |

CSS 変数:

```css
--led-foot-bar-bg: #fff9f0;
--led-foot-bar-h: 32px;
--led-col-body-h: 64px;
--led-col-main-h: 96px;
--led-foot-font: 15px;
--led-foot-site-font: 15px;
```

### 1.3 配置の原則

1. **1列＝1情報**（ラベル上・値中央・補足下）
2. **中央揃え**を基本（テロップは横スクロール例外）
3. **はみ出し禁止** — 128 px 幅内に収まるようフォントを自動縮小
4. **下帯は常にクリーム** `#fff9f0`、文字は黒 `#1a1a1a`
5. カード・影・細い枠線は使わない（LED で欠けるため）

## 2. タイポグラフィ

### 2.1 フォント

| 用途 | フォント | 理由 |
|------|----------|------|
| 日本語ラベル・テロップ | **Noto Sans JP** | 可読性・太字対応 |
| 数字（時刻・気温・WBGT） | **Inter** | 等幅数字・LED 向き |
| フォールバック | Hiragino Sans / Yu Gothic UI | 端末差吸収 |

### 2.2 文字色の基本ルール

| 背景 | 文字色 | 用途 |
|------|--------|------|
| 青・橙・赤など濃色 | `#ebebeb`（白寄り） | 通常のラベル・数値 |
| 黄・橙黄（注意・警戒） | `#000000` | `col-bg-dark-text` 時 |
| 下帯クリーム | `#1a1a1a` | 地点・出典・指針 |
| 強調（震度など） | `#FFE600` | 地震観測パネルの震度 |

### 2.3 サイズの目安（通常ループ）

| 要素 | サイズ | 太さ | 備考 |
|------|--------|------|------|
| 上バー・項目名 | 15〜20 px | 700 | シーンにより拡大 |
| 時刻（時:分） | **42 px**（最大） | 800 | 幅超過時 28 px まで縮小 |
| 観測数値 | **44 px** | 800 | シーン2本体 |
| 単位（℃・%） | 16〜20 px | 600〜700 | 数値の約 36〜40% |
| WBGT 数値 | **44 px**（最大56） | 800 | 112×64 内に収める |
| 下帯テキスト | **15 px** | 700 | 長い文は自動縮小 |
| 4日予報・日付 | 22 px | 700 | |
| 4日予報・気温 | 〜52 px | 800 | アイコンと横並び |

### 2.4 テロップ（割り込み）のサイズ

| 画面 | 1行目 | 2行目 | 備考 |
|------|--------|--------|------|
| 熱中症アラート | 最大 34 px | 約 58% | 256 px モジュール内 |
| 大雨／警報（標準） | 最大 34 px | 約 58% | 警告アイコン幅 52 px 確保 |
| 地震・直後1分 | **40 px** | — | 1行・超太字 900 |
| 地震・上帯「緊急地震速報」 | **18 px** | — | 赤帯内・繰り返し |

## 3. カラーパレット

### 3.1 共通色

| 名前 | コード | 使い方 |
|------|--------|--------|
| 下帯クリーム | `#fff9f0` | 全通常シーンの下帯 |
| 本文白 | `#ebebeb` | 濃色背景上の文字 |
| 本文黒 | `#1a1a1a` / `#000` | 明色背景・下帯 |
| 画面外背景 | `#1a1a1a` | PC プレビュー枠 |
| 初期／ほぼ安全 | `#308DD8` | 既定の本体青 |

### 3.2 WBGT レベル色（背景）

暑さ指数に応じて **上バー＋本体** の色が変わる。

| レベル | 条件 | 本体 | 上バー | 文字 |
|--------|------|------|--------|------|
| ほぼ安全 | 〜21未満 | `#308DD8` | `#55A5E6` | 白 |
| 注意 | 21〜25未満 | `#FFD92D` | `#FEE968` | **黒** |
| 警戒 | 25〜28未満 | `#FFBE2D` | `#FECD58` | **黒** |
| 厳重警戒 | 28〜31未満 | `#FF7E00` | `#FF9A38` | 白 |
| 危険 | 31以上 | `#D61914` | `#E94540` | 白 |
| 取得不可 | — | `#2a2a2a` | `#3a3a3a` | 白 |
| 提供期間外 | — | `#484848` | `#585858` | 白 |

### 3.3 気象庁・警戒レベル色（警報テロップ）

| 段階 | 背景 | 文字 | 用途 |
|------|------|------|------|
| L1 早期注意 | `#156082` | 白 | 早期注意情報 |
| L2 注意報 | `#F2E700` | 黒 | 注意報 |
| L3 警報 | `#FA2900` | 白 | 警報・高齢者等避難 |
| L4 危険 | `#AB00AA` | 白 | 危険警報・避難指示 |
| L5 特別 | `#000000` | 白 | 特別警報・緊急安全確保 |

白ベース警報（`rainwhite`）では外側を `#FFF9F0`、中央チップに上記色を載せます。

### 3.4 熱中症アラート色

| 種別 | 背景 | 1行目 | 2行目 | 点滅線 |
|------|------|--------|--------|--------|

| 特別警戒 | `#000000` | `#FF5A5A` | 白 | 白 |

### 3.5 地震色

| 部位 | 色 | サイズ／配置 |

## 4. シーン別レイアウト

### 4.1 ① 時刻（scene1）

```
+--32--+--32--+--32--+--32--+  日付ラベル 20px
|--64--|--64--|--64--|--64--|  時刻 42px x4面同一
+-----+-----+-----+-----+--+  下帯 32px クリーム
| 熊本市 | WBGT短文 … → スクロール
+--------------------------+
```

- 4列とも同じ日付・同じ時刻
- 下帯は 256 px 単位で「地点｜メッセージ」をシームレス横スクロール

### 4.2 ② 気象観測（scene2）

```
+ ラベル 20px -+
|   数値 44px  |  <- 128x96 が1パネル
+ 下帯メタ 15px+  観測時刻などを横スクロール
```

- 天気／気温／雨／風向／風速／湿度／気圧／最高最低／瞬間風速を順送り
- 最高・最低は白カード＋赤／青数字

### 4.3 ③ WBGT（scene4）

```
+ 暑さ指数／WBGT +  ラベル交互
|   28.5 ℃       |  数値大＋単位
+ 出典テキスト…  +  下帯スクロール
```

### 4.4 ④ 4日予報（scene5）

```
+ 今日 | 明日 | 明後日 | 明々後日 +
| 天気／気温 | … | … | … |
+ 熊本市 … +
```

- 今日列は 2 px 枠で強調（濃色背景＝白枠／注意・警戒＝黒枠）

### 4.5 ⑤ 多言語指針（scene3）

```
+ レベル名 x4（上32） +
| 256 | 256  2行テロップ横スクロール |
+ 指針文（下帯）… +
```

- 日・英・インドネシア・フィリピン・ベトナムを順に切替
- 言語ごとに 1・2行のフォントサイズ表あり（はみ出し時は縮小）

## 5. 割り込みデザイン

### 5.1 熱中症アラート / 避難情報

- **256×128 モジュール ×2** を横に並べる
- 上下に細い点滅ライン
- 本文は 2 行・中央揃え・横スクロール（周回で次段階へ）

### 5.2 気象警報（白ベース既定）

```
+ 上 40px：地域で発表／時刻／種別まとめ +  青系文字
| 中央：チップが右→左に流れる           |  段階色
+ 下：発表中の段階チップ（注意〜特別）  +
```

### 5.3 地震・直後1分（初報）

```
+ 緊急地震速報 緊急地震速報 … +     赤帯 32px・白18px
| [黄アイコン] 地名で地震発生　震度X　MX.X（気象庁） |
+------------------------------------+  黒背景・白40px
```

- アイコンは軽く横揺れアニメ
- 約1分後は 4 分割観測パネル（震源／M／深さ／震度）へ切替

## 6. モーション

| 種類 | 目安 | 用途 |
|------|------|------|
| シーン切替スライド | 約 450 ms | 次画面が右から入る |
| スクロール開始待ち | 約 1 秒 | 切替直後は静止 |
| 本文スクロール | 約 0.75 px/frame | 本番速度 |
| 下帯スクロール | やや遅め | 読みやすさ優先 |
| 警報ライン点滅 | 約 1.4 s 周期 | 注意喚起（急点滅は避ける） |
| 地震アイコン揺れ | 約 0.55 s | 初報のみ |

シームレス横スクロールは **同じ内容を2セット以上並べ、1セット幅でループ** する。

## 7. 使い方チェックリスト（デザイン変更時）

1. **512×128 の外に要素を出さない**
2. 新しい色を足すときは、気象庁／環境省の段階色と衝突しないか確認
3. 黄・橙黄背景では文字を黒にする（`col-bg-dark-text`）
4. 数字は Inter、日本語は Noto Sans JP
5. 長い文言はフォント縮小を先に試し、それでもダメならスクロール
6. LED 向けに **細い線・薄いグレー・半透明だけに頼らない**
7. デモ専用レイアウトを本番 CSS に混ぜない
