# 住之江 デジタルサイネージ デザイン仕様（MD方式）

対象ファイル:

- 四面体: `index-4face.html`（本番 **512×128**）→ プラットフォーム: `wbgt-cube-osaka-suminoe-4face.html`
- 五面体: `index-5face.html`（本番 **640×128** = コンテンツ512 + ロゴ128）→ プラットフォーム: `wbgt-cube-osaka-suminoe-5face.html`

基準単位: **px**（LEDネイティブ解像度。拡大表示はプレビュー時のみ）

---

## 1. キャンバス構成

| 項目 | 四面体 | 五面体 |
|---|---:|---:|
| 全体幅 | **512** | **640** |
| 全体高さ | **128** | **128** |
| コンテンツ領域 | **512×128** | **512×128** |
| ロゴ列 | なし（非表示） | **128×128**（右端） |
| 列分割 | 4列 × **128** | コンテンツ4列 × **128** + ロゴ1列 |
| 列ギャップ | **0** | **0** |

```
四面体:  [ 128 | 128 | 128 | 128 ] = 512
五面体:  [ 128 | 128 | 128 | 128 | 128(logo) ] = 640
```

## 7. シーン別デザイン要点

### Scene1（時計）

- 上: ラベル 20px / `#ebebeb`

表示順（128px×9）:

1. 天気 → 2. 気温 → 3. 暑さ指数 → 4. 湿度 → 5. 降水量 → 6. 風向き → 7. 風速 → 8. 気圧 → 9. 最高/最低

### Scene4（暑さ指数・環境省WBGT）

- ラベル「暑さ指数」「WBGT」交互
- 数値 44px + 単位 20px
- 背景は WBGT レベル色

### Scene5（4日予報・気象庁）

- 上: 今日/明日/明後日/明々後日 22px
- 中: 天気アイコン 58px + `/` 38px + 最高気温 52px
- 下: `最低℃ / 降水%` 13px（例: `28℃ / 30%`）

### Scene3（多言語指針） / Alert / RainWarn

- 指針: レベル色背景 + 20px ラベル
- 熱中症・大雨: セクション4.3 / 4.4 の専用パレット

## 10. デザインベース方針（MD方式サマリ）

1. **グリッド**: 128px カラム × 高さ128px を絶対基準にする  
2. **縦3段**: 32 / 64 / 32 を全シーンで共有する  
3. **色**: WBGT 5段階パレットを背景の唯一の主色源にする  
4. **文字**: 数値=Inter・和文=Noto Sans JP、コントラストは黄系背景のみ黒  
5. **四面/五面**: コンテンツ512は同一。差分は右端ロゴ128の有無のみ  

このMDをデザインベースとし、改修時は数値を本表から参照・更新してください。
