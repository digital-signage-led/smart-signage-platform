# 緊急地震速報 — デザイン仕様（512×128 固定）

他案件へ持ち出すときは **キャンバスを必ず 512×128px** に固定する。  
相対レイアウトや `%` 拡大は使わず、下記の **絶対px** をそのまま使うと形が崩れない。

対象ファイル:

- 正本相当: `index-4face.html`（`#sceneQuake`）
- プラットフォーム: `wbgt-cube-kumamoto-4face.html`（避難・地震プレビュー用）
- 同実装: `wbgt-cube-okinawa-kumejima-4face.html`

---

## 1. キャンバス（共通・崩さないための前提）

| 項目 | 値 |
|------|-----|
| 表示サイズ | **512 × 128 px** |
| 1面 | 128 × 128 px（×4面＝512） |
| `box-sizing` | `border-box` |
| `overflow` | `hidden`（はみ出し禁止） |
| フォント | `"Noto Sans JP", "Hiragino Sans", "Inter", sans-serif` |
| スクロール速度 | **1.6 px / frame**（約60fps想定） |

```
┌──────────────────── 512px ────────────────────┐
│ 上帯（赤） 30px                                │
├───────────────────────────────────────────────┤
│ 本体（残り） ※モードで中身が変わる              │
├───────────────────────────────────────────────┤
│ 下帯（観測パネル時のみ） 20px                   │
└───────────────────────────────────────────────┘
高さ合計 128px
```

---

## 2. 再生ルール（放送の流れ）

| フェーズ | 時間 / 回数 | デザイン |
|----------|-------------|---------|
| **A. 直後単独** | 発生から **60秒** | 黒ティッカー（黄アイコン＋大文字） |
| **B. 通常統合** | 通常ループに **3周**挿入 | 観測パネル（震源 / M / 深さ / 予測震度） |

- 到達秒・「0到達」バッジは **出さない**
- 上帯の△! アイコンは **付けない**（「緊急地震速報」文字のみ）
- 続報は表示更新のみ。レベル上昇や別イベントなら再び A から

## 5. フェーズA — 直後1分・黒ティッカー

下帯は **非表示**。本体高さ ≒ **98px**（128 − 30）。

| 項目 | 値 |
|------|-----|
| 背景 | `#111111` |
| 黄アイコン外枠 | **72 × 72 px** / 角丸 **10px** / 枠 **3px #111** / 地 `#FFE600` |
| アイコン内SVG | **56 × 56 px** |
| アイコン揺れ | `0.55s` 無限（±3deg） |
| 本文サイズ | **34px** / 字重 **900** / 字間 `0.02em` / 行高 `1.05` |
| 本文色 | `#FFFFFF` |
| アイコン↔文言 gap | 14px |
| セグメント padding | `0 36px 0 10px` |
| 折り返し | 禁止（`nowrap`・横スクロール） |

### 文言テンプレ

```
{震源}で地震発生。強い揺れに備えて下さい　予測震度{震度}　M{マグニチュード}（気象庁）
```

例: `熊本県熊本地方で地震発生。強い揺れに備えて下さい　予測震度5弱　M5.2（気象庁）`

## 6. フェーズB — 観測パネル（通常ループ用）

下帯 **あり**。本体高さ ≒ **78px**（128 − 30 − 20）。

| 項目 | 値 |
|------|-----|
| 背景 | `#1a120e` |
| 列数 | **4**（＝4面） |
| 1列幅 | **128px** 固定 |
| 1周幅 | **512px**（128×4） |
| 列の並び | 震源 → マグニチュード → 深さ → 予測震度 |
| スクロール周回 | 統合1回あたり **4周**（512px基準） |
| 列区切り | 右ボーダー 1px `rgba(255,255,255,0.14)` |
| 列内 | 縦中央・横中央 / gap **4px** / padding `2px 4px` |

### タイポ（列ごと）

| 要素 | サイズ | 字重 | 色 | 備考 |
|------|--------|------|-----|------|
| ラベル（震源など） | **13px** | 700 | 白 78% | 字間 `0.04em` |
| 数値（通常） | **32px** | 900 | `#fff` | M・深さ |
| 震源（長い地名） | **18px** | 900 | `#fff` | 6文字超で縮小・最大2行・高さ上限42px |
| 予測震度 | **40px** | 900 | `#FFE600` | 強調 |
| 単位 `km` | **13px** | 700 | 白 70% | 深さの下 |

### 下帯

| 項目 | 値 |
|------|-----|
| 高さ（帯の太さ） | **20px** |

| 左 | `出典：気象庁　{発表時刻}` |
| 右 | 地点名（例: `熊本市`） |

## 7. 感覚ガイド（微調整するときの目安）

| 変えたいもの | 触る値 | 目安 |
|--------------|--------|------|
| 上帯の太さ | `.qk-badges` height | 28〜32px（いま30） |
| 上帯の字 | `.qk-badge-txt` | 15〜18px（いま17） |
| 単独の本文 | `.qk-msg` | 30〜36px（いま34）・1行維持 |
| 黄アイコン | `.qk-icon` | 本体高さの約70%（いま72） |
| 観測の数値 | `.qk-obs-val` | 28〜34px（いま32） |
| 予測震度 | `.qk-obs-inten` | 数値より +6〜10px（いま40） |
| 下帯の太さ | `.qk-foot` height | 18〜22px（いま20） |

**崩れる操作（禁止）**

- 512×128 以外への `%` / `vw` スケール任せ
- 観測列を 128px 以外にする（4面同期が崩れる）
- 単独本文の折り返し許可（LEDで潰れる）
